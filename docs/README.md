## 子目录

| 目录 | 内容 |

## 阅读顺序建议

1. 想知道这东西是什么 → 仓库根 [README](../README.md) §1
2. 想验收 → `04`（演示脚本）→ `01`（判定口径）→ `TestReport`（证据）
3. 想改代码 → `03`（构建与单测）→ `01` §3/§4（规则）→ `02`（内容格式）
4. 想知道为什么这么设计 → `PROGRESS` §4 的踩坑表 + `TestReport` §4 的缺陷表
