### 0.1 Kotlin 侧已经真跑过了（不需要 IDE）

```powershell
powershell -File tools/run-kotlin-tests.ps1   # 自动下载编译器 + JUnit，编译并执行
```

当前结果：**16/16 通过**（`EngineTest` 15 + `FixtureTest` 1，后者内部跑 42 条 fixture）。

这条路径实测抓出了三个只有真编译/真运行才会暴露的问题，已修：

| 问题 | 现象 | 根因 |
| --- | --- | --- |
| 嵌套注释 | `FixtureTest.kt:176 Unclosed comment` | Kotlin 块注释**可嵌套**，KDoc 里写了 `fixtures/*.json`，其中的 `/*` 打开了嵌套注释 |
| setFlags 反序列化 | 16 个用例全挂：`Expected start of the object '{', but had '['` | kotlinx 的 `Pair` 默认按对象序列化，而内容 JSON 是紧凑数组 `["accepted", true]` → 已加 `FlagPairSerializer` 按两元素数组读写 |
| 默认值被省略 | fixture `apply-05/06` 报 `state.seq: 缺少字段` | `Json` 默认 `encodeDefaults=false`，`seq=0` 等默认值不出现 → 断言用 Json 已开 `encodeDefaults=true` |

因此 **Android 侧的 `gradlew :domain:test` 大概率直接绿**；鸿蒙侧仍需 DevEco 跑 Hypium（无可用编译器，未验证）。

## 6. 常见报错对照表

### Gradle 侧

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Could not resolve/connect`、下载 Gradle 超时 | 网络或代理 | 本机 443 时通时断；先 `curl -s -o NUL -w "%{http_code}" https://services.gradle.org` 试直连，不行就在 `gradle.properties` 里加 `systemProp.https.proxyHost/Port` 指向 Clash |
| `Android Gradle plugin requires Java 17` | JDK 版本低 | `File → Settings → Build Tools → Gradle → Gradle JDK` 选内置 17 |
| `Unresolved reference: libs` | 版本目录没被识别 | 确认 `android/gradle/libs.versions.toml` 存在，且 Sync 成功 |
| `Unresolved reference: initialState` 之类 | 引擎函数缺失 | 先跑 `python tools/preflight.py`，这类"调用点 vs 声明"不一致它能抓 |
| `Compose compiler plugin` 相关错误 | Kotlin 2.x 需要 `kotlin-compose` 插件 | 已在 `app/build.gradle.kts` 声明；若报错检查 Kotlin 版本与 AGP 是否匹配（2.1.0 / 8.7.3） |
| `SDK location not found` | 没装 Android SDK | Android Studio 首次启动会引导下载；或写 `android/local.properties` 的 `sdk.dir`（该文件已被忽略） |

### DevEco 侧

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Cannot find the SDK` / `compatibleSdkVersion` 不匹配 | SDK 版本低于 API 12 | SDK Manager 装 HarmonyOS NEXT API 12+，或把 `build-profile.json5` 的 `compatibleSdkVersion` 改成你装的版本 |
| 提示签名配置缺失 | `signingConfigs` 为空 | `File → Project Structure → Signing Configs` 勾 **Automatically generate signature**（需登录华为账号） |
| `Cannot resolve @ohos/hypium` | 依赖没装 | Sync 会自动 `ohpm install`；不行就在 `harmony/` 下执行 `ohpm install` |
| `TextDecoder.decodeToString is not a function` | API 名称/版本差异 | 改用 `decoder.decodeWithStream(bytes)`（同文件两处），或把 `compatibleSdkVersion` 提到你 SDK 的实际版本 |
| `as` 断言报 `Type 'Object' is not assignable` | ArkTS 严格类型 | `CaseLoader.parse` 里改成 `JSON.parse(text) as object as CaseFile` |
| `pages/Index` 白屏 | rawfile 里没有内容 | 跑 `tools/sync-case.ps1` 后重新构建（副本目录被 git 忽略，clone 下来是空的） |
| 真机跑测试提示无设备 | 没连设备/模拟器 | DevEco 的 Device Manager 起模拟器；`hvigorw test` 需要已连接的目标 |
