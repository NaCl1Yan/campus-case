## 2. 单元测试（Hypium 22 个 `it`）

### 2.1 两条路径都能跑

**A. IDE（推荐，能看树状结果）**

1. DevEco → `File → Open → E:\campus-case\harmony`
2. 左侧 `entry/src/ohosTest/ets/test` 右键 → **Run 'All Tests in 'test''**
3. 期望：`测试已通过：22 / 22`，耗时约 150 ms（截图 `docs/screenshots/hypium-run-22.png`）

**B. 命令行（CI 用，无需 IDE）**

```powershell

& $hdc install -r harmony\entry\build\default\outputs\default\entry-default-unsigned.hap
& $hdc install -r harmony\entry\build\default\outputs\ohosTest\entry-ohosTest-unsigned.hap
& $hdc shell "aa test -b com.nacl1yan.campuscase -m entry_test -s unittest OpenHarmonyTestRunner -s timeout 60000 -w 120"
```

期望结尾：

```
OHOS_REPORT_RESULT: stream=Tests run: 22, Failure: 0, Error: 0, Pass: 22, Ignore: 0
TestFinished-ResultCode: 0
TestFinished-ResultMsg: your test finished!!!
```

原始日志：`docs/evidence/hypium-aa-test.log`。

### 2.2 22 个用例是什么

| 套件 | 数量 | 覆盖 |
| --- | --- | --- |
| `Engine`（`Domain.test.ets`） | 14 | 门控顺序、撬锁关闭、幂等、非法阶段跳转、回退边、连线规则、双链成立、结局拦截、进度钳制、回放幂等、完整链路 |
| `Fixtures.AC18`（`FixtureRunner.test.ets`） | 8 | 遍历 `Fixtures.generated.ets`（由 `shared/fixtures` 生成）跑 42 条判定用例：gate / sceneGate / apply / combine / ending / progress / replay |

### 2.3 三个坑（都已修，别再踩）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| Run 立刻失败：`'Fixtures(AC-18)' is an invalid describe value` | Hypium 的 describe 值只允许字母/数字/下划线/点，且首字符必须是字母 | 套件名改 `Fixtures.AC18` |
| Run 一直停在「正在运行测试…」，`aa test` 只报 `Timeout: user test is not completed` | Hypium 报告链路 `OhReport → SysTestKit.print → delegator.print()` 需要一个**已启动的 UIAbility** 作宿主；没有时该 Promise 永不 resolve，`suiteStart` 的第一个 `await` 就卡死 | 新增 `ets/testability/TestAbility.ets`（`onCreate` 里跑 Hypium），`module.json5` 声明该 Ability；runner 改为 `startAbility(TestAbility)` |
| 崩溃：`Cannot read property startAbility of null` | runner 在模块顶层取 `abilityDelegatorRegistry.getAbilityDelegator()`，那时还是 `null` | 改为在 `onRun()` 内取，并对 null 做防御 |

> 结论：Hypium 既能跑在 IDE，也能跑在 `aa test`，前提是「有宿主 Ability + 合法 describe 名」。

## 5. 常见报错对照（DevEco 侧）

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `hvigor ERROR: Invalid project path` | 工程路径含中文/空格 | 挪到纯 ASCII 路径；或让脚本自动镜像到 `%LOCALAPPDATA%\campus-case-build` |
| `Cannot Open Project: ... contain chinese characters` | DevEco 打开的是中文路径 | 同上；且要选 `harmony/` 子目录，不是仓库根 |
| `Cannot find the SDK` / `compatibleSdkVersion` 不匹配 | SDK 版本低于 API 12 | SDK Manager 装 HarmonyOS NEXT API 12+，或改 `build-profile.json5` |
| `Cannot resolve @ohos/hypium` | 依赖没装 | 在 `harmony/` 下 `ohpm install`，或让 IDE Sync 一次 |
| `pages/Index` 白屏 | rawfile 里没有内容副本 | 跑 `tools/sync-case.ps1` 再重装（副本目录被 git 忽略，clone 下来是空的） |
| `System Low Memory` 告警、Run 偶发超时 | IDE + 模拟器吃内存 | 关掉多余窗口；`Help → Change Memory Settings` 调到 3072 后重启 |
| 真机跑测试提示无设备 | 没连设备/模拟器 | DevEco 的 Device Manager 启动模拟器；`hdc list targets` 应非空 |
